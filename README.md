Pong Game 🎮

A classic implementation of the retro Pong Game built using Python's Turtle Graphics library. This project replicates the iconic arcade-style two-player game, where players control paddles to hit a ball back and forth across the screen.

Features ✨

Two-player gameplay: Player 1 controls the left paddle, and Player 2 controls the right paddle.
Score tracking: Displays the score for both players on the screen.
Ball mechanics: The ball bounces off the paddles and walls, with realistic movement.
Game boundaries: Players lose points if they miss the ball.
Smooth controls: Move paddles up and down with assigned keys.
